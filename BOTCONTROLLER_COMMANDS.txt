──────────────────────────────────────────────────────────────────────
 1️⃣  BOT ADD / MANAGE
──────────────────────────────────────────────────────────────────────
  .addbottoken <token>  ✅ token LIVE verify karke bot add
                          (1st, phir 2nd, 3rd... slots)
     ex: .addbottoken 123456789:AAHxyz...
     ❌ dead/revoked token apne aap reject (FROZEN detect)

  .addnewbotauto [n]    🆕 BotFather se KHUD naya bot bana deta hai
                          — name: worker · username khud generate
                            (hamesha 'bot' par khatam, e.g. worker482913_bot)
                          — username taken ho toh dobara try karta hai
                          — token auto-register + bot ko /start bhi
     ex: .addnewbotauto      → 1 naya bot
          .addnewbotauto 3   → 3 naye bots ek saath

  .delbottoken <n>      ✅ nth bot delete (slots auto-shift: 2nd delete
  .delbot <n>              → purana 3rd ab 2nd ban jayega)

  .listbots / .botlist  ✅ saare bots ki list (❄️ frozen bhi dikhta hai)
  .monitorb             ✅ LIVE status: kaun online 💚 + SAB KA NAAM
  .refreshb             ✅ sab bots reconnect (frozen clear attempt)

──────────────────────────────────────────────────────────────────────
 3️⃣  SPAM SYSTEM
──────────────────────────────────────────────────────────────────────
  .spamb <n> <sec> <text>   ✅ SAB bots text spam
     ex: .spamb 10 1 hello   → 10 baar, 1 second gap
          .spamb 50 0.1 yo   → 0.1s gap bhi (NO lower limit)
  .spamb1-2 <n> <sec> <txt> ✅ sirf specific bots
     ex: .spamb1-2 10 1 hi  → sirf 1st + 2nd bot
  .sspam <n> [sec]          ✅ USER sticker spam (sticker par reply karke)
  .sspamb <n> [sec]         ✅ BOTS sticker spam (reply karke)
     ex: sticker par reply + .sspamb 10 .1

──────────────────────────────────────────────────────────────────────
 4️⃣  RAID SYSTEM — v3 REWRITE 🆕
──────────────────────────────────────────────────────────────────────
  .raid [n] [text]      ✅ user raid — reply optional, custom text,
                          saved slots rotate (1st → 2nd → 3rd…)
     ex: .raid 20  ·  .raid 20 hello  ·  reply + .raid 20

  .raidb [slots] <n> [txt] 🆕 BOT raid — ab reply OPTIONAL hai
     ex: reply + .raidb 10     → victim par bot raid
          .raidb 10 hello      → pura chat raid (bina reply)
          .raidb1-3 10         → sirf 1st-3rd bots

  📜 RAID MESSAGE SLOTS (saverm system):
  .saverm <text>        ✅ slot save — 1st, phir 2nd, 3rd...
     ex: .saverm kya kar rhe ho   → 1st slot
          .saverm oye {name}       → 2nd slot
  .listrm               ✅ sab saved slots list
  .delrm <n>            ✅ nth slot delete → AUTO-SHIFT
     (3rd delete karo → purana 4th ab 3rd ban jayega)
  .delallrm             🆕 sab slots ek saath delete

  .rrt                  ✅ REPLY-RAID TURBO (user): kisi par reply karke
                          likho → uska HAR message reply me saved slots
                          me se ek-ek aayega
  .rrtb [slots]         ✅ BOTS wala RRT  · ex: .rrtb  /  .rrtb2-3
  .stoprrt              ✅ sab RRT band

  🛠 v7.4 NOTE: purane error-wale .drraid + uska listener HATA diye gaye.
     Ab sirf .rrt / .rrtb hai (better + bots support).

  .setraid <text>       ✅ raid text template ({name}/{tag} placeholders)
  .listraid / .delraid  ✅ saved text dekho / delete

 7️⃣  COPYCAT — .ct / .ctb
